# 有字与无字的配对制作

用于当前图片的有字/无字互转、同主题双版交付，以及多种风格的成套示例。

## 两版之间保持什么

先从输入图和已确认简报中提取共同约束：

- 主题及其表达的观点或情绪。
- 主体身份、关键物件和视觉母题，例如「被摄影条带切开的侧脸」，而不只记住「一个人」。
- 风格编号、主辅色、材质、摄影或插画手法、图形语言。
- 画幅、目标尺寸和重要内容的安全区。

两版一眼可识别为同一组。差异主要来自主体的位置、大小、裁切、局部延展、图形关系和留白分配。保持设计语言稳定，不为了填满空白增加无关场景、人物或装饰。

## 有字转无字

1. 阅读原图可见文字，结合文章或已确认主题，识别原先由文字承担的信息。
2. 保留最能表达该信息的主体和母题；通过大小、疏密、对照、连接、断裂等现有视觉关系，让主题在没有标题时也能成立。
3. 重新平衡原文字区域与图像区域。可把主体适度居中或放大、延展已有图层、重新安排同一组物件；保留有意义的留白，而不是留下被擦除标题的空位。
4. 使用原图作为原生生图的图像输入，写清保留项和允许改变的构图项。对尚未在对话中展示过的本地图片，先查看图片。
5. 检查所有标题、副标题、边注、字母和数字均已移除，并确认画面仍完整、母题仍一致。

只有用户明确要求「只去字，保留原布局」或「做后期排字底图」时，才采用保持构图、仅移除文字的处理方式。

提示词表达示例：

> 以输入图作为同一作品的设计参考。保留同一个侧脸、摄影切片、黑白红配色、纸纹和红色细线；根据“注意力被切碎”的主题制作无需文字的完整画面。将侧脸适度居中，延展已有摄影条带并平衡留白。变化集中在构图，不新增另一套故事或物件。全图不出现文字。

## 无字转有字

1. 沿用用户给出的标题、副标题与补充文字；缺失时只询问需要补充的文案。
2. 使用当前无字图作为原生生图参考，优先调整主体位置、画面裁切和留白，为标题建立清晰层级。
3. 按所选风格设置字体气质、大小、行距与主辅色。要求完整、规范的汉字字形；套印、故障或笔触效果不要破坏字形识别。
4. 保留主体与母题，避免把标题直接压到关键人物或物件上。文字难以清晰容纳时，提出精简文案或拆图方案。
5. 核对每个可见文字块，包括笔画完整性、分行、顺序和缩小后的可读性。

## 同时制作有字与无字两套

- 用户指定先做哪一版时遵从；否则先制作更能代表当前用途的基准版本。
- 后续配对版本以对应基准图为图像输入，逐张转换。11 种风格示例应形成 11 对，不把「封面、插图、信息卡」三种用途误当成风格数量。
- 同一对共用风格编号、主题、母题、画幅与尺寸；两套按相同编号排列。
- 公众号横版与方版仍分别构图；有字/无字版本不能代替横版/方版规格。简报写明实际交付文件数。
- 此配对规则优先于普通系列「多项视觉变化」的节奏建议：配对图应控制差异，保持同组识别。

## 核验与归档

把两版并排检查：主体与母题是否一致，风格是否只是换色，纯视觉是否还有原文案留下的空洞，文字是否规范可读，是否新增无关装饰，尺寸是否相同。

文件共用原有主题、母题和编号，以「有字」「无字」区分，例如：

```text
<标题>-封面-<风格编号>-<母题>-有字-01.png
<标题>-封面-<风格编号>-<母题>-无字-01.png
```

保留基准版和已交付版本，修订另存版本后缀；不要为完成转换而删除原图。交付时说明转换方向与构图调整点，并提供对应两版。
